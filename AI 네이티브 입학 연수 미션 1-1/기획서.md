# 영화 티어 리스트 기획서

## 1. 누가 쓰나

- **사용자:** 영화를 좋아하고, 자신이 본 영화를 등급별로 정리하고 싶은 사람
- **사용 목적:** 영화에 대한 개인적인 평가를 정리하고, 영화를 좋아하는 친구들과 자신의 취향에 관해 이야기하기 위해 사용한다.

## 2. 무엇을 하려고

사용자가 본 영화 8편을 개인적인 평가에 따라 3개 등급으로 분류하는 영화 티어 리스트를 만든다.

- 영화마다 원하는 등급을 지정할 수 있다.
- 분류된 영화를 등급별로 모아 볼 수 있다.
- 이미 분류한 영화의 등급을 변경하거나 미분류 상태로 되돌릴 수 있다.
- 분류 결과를 자동 저장하여 나중에 다시 열었을 때도 확인할 수 있다.

### 등급 체계

| 등급 | 이름 | 의미 |
| --- | --- | --- |
| S | 최애 영화 | 몇 번이고 다시 보고 싶은 영화 |
| A | 좋았던 영화 | 재미있게 봤고 추천하고 싶은 영화 |
| B | 아쉬웠던 영화 | 내 취향에는 조금 아쉬웠던 영화 |

## 3. 화면과 동작

### 3.1 메인 화면

메인 화면에는 다음 요소를 표시한다.

- **영화 티어 리스트:** S, A, B 등급별 영역
- **미분류 영화 목록:** 아직 등급을 지정하지 않은 영화
- **분류 진행률:** 전체 8편 중 몇 편을 분류했는지 표시
- **자동 저장 상태:** 분류 결과의 저장 상태 표시

### 3.2 영화 분류

1. 사용자가 영화 목록에서 원하는 영화를 클릭한다.
2. 해당 영화의 제목과 등급 선택 화면이 나타난다.
3. 사용자가 S, A, B 중 하나를 선택한다.
4. 선택한 영화가 해당 등급 영역에 표시된다.
5. 변경된 분류 결과가 자동 저장된다.

**영화 이동 방식:** 드래그 앤 드롭이 아닌 클릭을 통한 등급 선택 방식을 사용한다.

### 3.3 등급 변경 및 초기화

- 이미 분류한 영화를 다시 클릭하면 등급을 변경할 수 있다.
- 미분류로 되돌리기를 선택하면 해당 영화가 미분류 목록으로 이동한다.
- 전체 초기화 기능을 통해 모든 영화의 등급을 초기 상태로 되돌릴 수 있다.

### 3.4 저장 및 결과 활용

- 영화 등급 변경 시 결과를 자동 저장한다.
- 같은 브라우저에서 다시 열었을 때 기존 결과를 불러온다.
- 현재 구현에는 결과 텍스트 복사, JSON 백업 파일 저장 및 불러오기 기능이 포함되어 있다.

단, 저장 기능은 브라우저의 로컬 저장소를 사용하므로 다른 기기에서의 동기화는 보장하지 않는다.

### 4.2 영화별 데이터

- 영화 식별 정보

현재 구현에서는 영화 제목, 개봉 연도, 이모지와 색상 배경을 사용한다.

## 5. 완성 기준

다음 조건을 만족하면 기본 기능이 완성된 것으로 판단한다.

- [ ] 지정한 영화 8편이 모두 화면에 표시된다.
- [ ] S, A, B의 3개 등급이 구분되어 표시된다.
- [ ] 영화를 클릭하면 등급을 선택할 수 있다.
- [ ] 선택한 영화가 해당 등급 영역으로 이동한다.
- [ ] 이미 분류한 영화의 등급을 변경할 수 있다.
- [ ] 영화를 미분류 상태로 되돌릴 수 있다.
- [ ] 분류 진행률이 실제 분류 결과에 맞게 표시된다.
- [ ] 분류 결과가 자동 저장된다.
- [ ] 같은 브라우저에서 다시 열어도 기존 분류 결과가 유지된다.
