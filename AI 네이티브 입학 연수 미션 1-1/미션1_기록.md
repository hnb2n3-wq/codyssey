# 미션 1 기록

- **AI A:** ChatGPT  
  **주요 대화 캡처 파일명: 미션1_GPT 대화 캡처
- **AI B:** Gemini  
  **주요 대화 캡처 파일명: 미션1_제미나이 대화 캡처

## AI가 물어서 내가 정한 것

ChatGPT와 대화하면서 영화 티어 리스트의 기본 설정을 하나씩 정했다.

- **등급 개수:** 3단계(S: 최애 영화 / A: 좋았던 영화 / B: 아쉬웠던 영화)
- **영화 이동 방식:** 드래그 앤 드롭이 아니라 영화를 클릭한 뒤 등급 선택
- **저장 방식:** 분류 결과 자동 저장
- **영화 자료:** 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리 총 8편

Gemini와의 질문·응답 내용은 제공된 B 초안 HTML만으로는 확인할 수 없어 별도로 적지 않았다.

## 같은 행동으로 비교한 결과

> 아래 표는 **두 HTML 파일의 코드에서 확인되는 동작**을 비교한 것이다. 실제 브라우저에서 같은 행동을 직접 수행한 테스트 기록은 아니므로, 실행 결과를 확인했다고 단정하지 않는다.

| 비교할 행동 | 기대 결과 | A(ChatGPT) 코드 확인 결과 | B(Gemini) 코드 확인 결과 |
|---|---|---|---|
| 처음 HTML 파일 열기 | 지정한 영화 8편과 S/A/B 및 미분류 목록이 나타남 | 8편, 3개 등급, 미분류 목록 구성 | 8편, 3개 등급, 미분류 목록 구성 |
| 영화 클릭 후 S등급 선택 | 영화가 S등급으로 옮겨지고 진행률이 바뀜 | 등급 변경 → 저장 → 화면 갱신 순서로 구현 | 등급 변경과 화면 갱신은 구현됐지만, 모달을 닫으며 선택한 영화 ID를 지운 뒤 이를 다시 참조하는 코드가 있어 오류가 발생할 가능성이 있음 |
| 분류한 영화를 다시 클릭하기 | 다른 등급으로 바꿀 수 있음 | 등급 재선택 기능 구현 | 등급 재선택 기능 구현(위 오류 가능성 존재) |
| 새로고침 또는 다시 열기 | 이전 분류 결과 유지 | 브라우저 `localStorage` 저장 및 불러오기 구현 | 브라우저 `localStorage` 저장 및 불러오기 구현 |
| 전체 초기화 | 모든 영화가 미분류로 돌아감 | 확인창과 초기화 기능 구현 | 확인창과 초기화 기능 구현 |
| 결과 백업 | 현재 등급을 파일로 저장하고 다시 불러올 수 있음 | JSON 백업 저장·불러오기 구현 | JSON 백업 저장·불러오기 구현 |

두 초안 모두 실제 포스터 대신 이모지를 사용하며, **초기 영화 8편의 등급 분류**를 중심으로 구성되어 있다.

## 선택한 파일명과 고른 이유

- **선택할 파일명(추천): `영화_A_초안.html`**
- **고른 이유:** A는 영화 클릭 → 등급 선택 → 자동 저장 → 화면 갱신의 흐름이 비교적 명확했고, 저장이 제한되는 경우 안내하는 처리도 포함되어 있다. B 역시 전체적인 디자인과 기능이 잘 구성되어 있지만, 등급 선택 후 선택 영화 정보를 다시 참조하는 부분에서 오류 가능성이 확인되었다. 따라서 **기본 기능의 안정성을 우선하여 A 초안을 선택하는 것이 적절하다고 판단했다.**

※ 최종 선택은 실제 두 파일을 브라우저에서 열어 비교한 뒤 확정할 수 있다.

## 수정 여부

**수정하지 않음.**

### 고치지 않았다면 그대로 둔 이유

이번 미션에서는 두 AI가 처음 생성한 결과물을 비교하는 것이 목적이라고 생각했다. 따라서 A와 B 모두 코드를 직접 수정하지 않고 **초안 상태 그대로** 남겼다. 이후 영화 추가 기능과 실제 포스터 표시 방식 등을 논의하며 기획서를 발전시켰지만, 그 내용은 미션 1에 제출하는 초안에는 반영하지 않았다. 초안과 이후 개선 버전을 구분하면 AI별 최초 결과를 비교하기에도 더 적절하다고 판단했다.

## (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유

같은 기획서를 바탕으로 두 AI가 생성한 웹페이지도 디자인과 코드 구성에 차이가 있다는 점을 이야기해 보고 싶다. 겉으로 보이는 화면뿐 아니라 **실제 클릭 동작, 오류 처리, 저장 기능까지 검토**해야 완성도를 판단할 수 있다는 점이 흥미로웠다.
